Motorwise CRM — UI/UX Improvement PRD

Document Version: 3.0
Product: Motorwise CRM
Scope: UI/UX redesign of the existing used-car dealership CRM
Target Business: Single dealership / ~200 cars / small-to-medium sales team
Primary Users: Sales Executives, Sales Managers, Owner/Admin
Platform: Desktop-first responsive web application, optimized for mobile sales usage

1. PRODUCT OBJECTIVE

Motorwise already has the right basic structure:
- Dashboard
- Leads
- Test Drives
- Pipeline
- Inventory

The next step should not be adding unnecessary modules.

The objective is to make these modules feel like one connected dealership operating system.

The redesigned CRM should allow a salesperson to understand within a few seconds:
- Who do I need to call today?
- Which customers are overdue?
- Which customers want which cars?
- Which test drives are coming up?
- Which deals are close to booking?
- Which cars are sitting too long?

The key UX principle should be:
Motorwise tells the employee what to do next instead of only showing stored data.

2. CURRENT UI ASSESSMENT

What is already good:
- Clean dark theme
- Easy-to-understand sidebar
- Large readable typography
- Consistent card style
- Logical primary navigation
- Clear branding
- Dashboard is not overloaded

Main problems:
1. Too much unused screen space.
2. Dashboard does not tell the salesperson what to do next.
3. KPI cards provide totals but little operational value.
4. No visible follow-up information.
5. No overdue lead warning.
6. No quick-add actions.
7. No global search.
8. Navigation icons use emoji-like styling and feel inconsistent.
9. Profile/header area consumes space without providing actions.
10. Recent Activity is too large relative to its importance.
11. Pipeline information is missing from dashboard.
12. Inventory ageing is missing.
13. No upcoming test-drive section.
14. No role-specific dashboard.
15. No clear priority hierarchy between urgent and informational items.

3. UX PHILOSOPHY

3.1 Action First
Important screens should prioritize:
- What needs attention
- Who needs a call
- What is overdue
- What is scheduled next

Instead of only:
- Total leads
- Total cars
- Total sales

3.2 Maximum 2–3 Clicks
Common actions should take no more than 2–3 clicks.
Examples:
Lead → Call
Lead → Schedule Follow-up
Lead → Schedule Test Drive
Car → View Interested Customers
Lead → Book Vehicle

3.3 Minimal Data Entry
Salespeople do not want to fill long forms.
Initial lead creation should take around 15–30 seconds.
Detailed information can be added later.

3.4 One Source of Truth
Customer, car, test drive, follow-up and deal information should be connected.
A salesperson should not have to manually update:
Lead = Booked
Car = Reserved
Deal = Booking

One action should update connected records automatically.

3.5 Mobile-Friendly Sales Workflow
Sales executives will frequently use Motorwise while:
- Calling customers
- Walking around the showroom
- Standing beside vehicles
- Conducting test drives
- Speaking to walk-in customers

Core actions must work exceptionally well on mobile.

68. ACCEPTANCE CRITERIA

The redesign is successful when a salesperson can:
1. Add a lead in under 30 seconds.
2. Find an existing customer using phone number quickly.
3. See every follow-up due today immediately after login.
4. Identify overdue customers without opening multiple pages.
5. Call or WhatsApp a customer directly from Motorwise.
6. Link a customer with one or more cars.
7. Schedule a test drive in a few clicks.
8. Move a customer through the sales process without manually updating multiple modules.
9. Create a booking that automatically reserves the vehicle.
10. Complete a sale that automatically updates the customer, lead, deal and vehicle.
11. Use the essential CRM workflow comfortably from a phone.

A manager should be able to answer within approximately 30 seconds:
- How many leads came today?
- How many are untouched?
- Which salesperson has overdue follow-ups?
- How many test drives are happening today?
- How many deals are in negotiation?
- Which vehicles have been sitting for over 90 days?
- How many cars were sold this month?

- Fancy 3D charts

70. FINAL PRODUCT DIRECTION

The current Motorwise interface looks like a clean CRM prototype.
The redesign should turn it into a daily dealership workspace.

The biggest improvement should not be visual decoration. It should be information priority.

Today the dashboard primarily tells the salesperson:
“There are 0 leads, 0 test drives, 0 cars and 0 sales.”

The improved version should eventually tell the salesperson:
“You have 3 new customers, Rahul needs a call at 10:30, Suman's follow-up is overdue, your Creta test drive starts at 12:00, and two customers are currently negotiating.”

That difference is what will make Motorwise feel like a genuine industry CRM rather than just a database with a dark UI.

HIGHEST-PRIORITY REDESIGN

For the current Motorwise dashboard, redesign in this order:
1. Header
2. KPI/action cards
3. Today's Actions
4. Pipeline
5. Upcoming Test Drives
6. Inventory Alerts
7. Compact Recent Activity
