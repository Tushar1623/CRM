# Motorwise Used Car Dealership CRM

A full-stack, production-ready Customer Relationship Management (CRM) system designed for second-hand automotive dealerships.

---

## 🚀 Running the Application

### 1. Start Backend API Server
```powershell
# In the root directory (e:\CRM)
npm start
```
- **Backend URL**: `http://localhost:3000`

### 2. Start Frontend Web Client
```powershell
# In the client directory (e:\CRM\client)
cd client
npm run dev
```
- **Application URL**: `http://localhost:5173`

## 🛠️ Key Modules & Features

- **Dashboard**: Live sales pulse, dynamic today's action center, scheduled test drives, and pipeline progress bars.
- **Theme Customization**: Toggle seamlessly between **Light Theme** (clean white surfaces, dark navy sidebar, orange branding) and **Dark Theme** (slate dark mode) using the Sun/Moon toggle in the top bar.
- **Leads & Pipeline**: Track customer requirements, buying timelines, vehicle interest, and pipeline stages from inquiry to sale.
- **Inventory Management**: Used car fleet tracking with specs, pricing, and availability statuses.
- **Test Drives & Follow-ups**: Direct appointment scheduling, call logging, and direct WhatsApp shortcuts.
- **Deals & Deliveries**: Track booking tokens, selling prices, auto loan/financing status, and vehicle delivery.
- **Reports**: Conversion funnel metrics and sales leaderboard.
