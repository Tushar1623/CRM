Motorwise CRM
Used Car Dealership CRM – Industry-Level Basic Version
PRD Version: 2.0
Target: Single used-car dealership, approximately 200 cars
Users: Owner, Sales Manager, Sales Executives
Platform: Web first, mobile responsive
Recommended backend: Supabase/PostgreSQL
Goal: Keep the CRM simple enough for salespeople to actually use while giving management complete visibility.

1. CURRENT PRODUCT REVIEW

Current Lead Management screen has:
- Customer name
- Phone
- Email
- Lead source
- Priority
- Add Lead
- Basic lead table
- Dashboard
- Leads
- Inventory

This is a good starting point.

However, the current form is mainly collecting a contact rather than creating a usable sales lead.

A salesperson should be able to understand something like:
“Rahul called looking for a 2021–2023 automatic Creta, budget ₹10 lakh, wants to buy this month, prefers white, test drive Saturday, next call Friday at 11 AM.”

The CRM needs to capture that sales context.

56. IMPORTANT AUTOMATION RULES

Rule 1:
New lead -> Status = New

Rule 2:
Customer contacted -> Status = Contacted

Rule 3:
Test drive scheduled -> Lead = Test Drive

Rule 4:
Negotiation entered -> Lead = Negotiation

Rule 5:
Booking received -> Lead = Booked, Vehicle = Reserved

Rule 6:
Deal completed -> Lead = Won, Vehicle = Sold, Deal = Completed

Rule 7:
Lead marked Lost -> Require lost reason

Rule 8:
Completed follow-up -> Ask for next action

Rule 9:
Duplicate phone -> Open existing customer
