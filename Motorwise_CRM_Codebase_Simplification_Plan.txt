Repository: Tushar1623/CRM
Goal: Make the CRM faster, easier to understand for beginners, and maintainable with minimal code, files, and folders.

==================================================

- Hard-coded demo users

19. CREATE ONE API HELPER
==================================================

Add one file:

client/src/api.js

Purpose:
Remove repeated fetch code from every page.

Recommended:

const API = import.meta.env.VITE_API_URL || 'http://localhost:3000';

export async function api(path, options = {}) {
  const token = localStorage.getItem('token');

  const res = await fetch(`${API}${path}`, {
    ...options,
    headers: {
      'Content-Type': 'application/json',
      ...(token && { Authorization: `Bearer ${token}` }),
      ...options.headers
    }
  });

  if (!res.ok) {
    const data = await res.json().catch(() => ({}));
    throw new Error(data.error || 'Request failed');
  }

  return res.json();
}

Then:

const leads = await api('/api/leads');

instead of repeating:

fetch('http://localhost:3000/api/leads')

throughout the app.
