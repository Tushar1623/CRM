# Database Architecture Notice (ARCHIVED)

> [!NOTE]
> **PostgreSQL / Supabase Schema Status**: ARCHIVED
> Per the **Motorwise CRM Database Correction Plan (v1.0)**, the active production database architecture is **MongoDB Atlas + Mongoose**.
> Do not use PostgreSQL and MongoDB simultaneously in the same CRM deployment.

The `schema.sql` file in this directory is retained solely for historical reference. Active database schemas, models, and indexes are defined in `models/` using Mongoose for MongoDB Atlas.
